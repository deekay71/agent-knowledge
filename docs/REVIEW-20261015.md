## Limits retained explicitly

- Schema-valid claims can still be false; approved metadata is a declaration, not proof of rights.
  No semantic contradiction detector, secret scanner or full-repository confidentiality certification.
  Review includes actual prose, source permissions, project boundaries and evidence content.
- Scope validation governs managed raw/wiki content. Files elsewhere in the repo, history and
  arbitrary detail strings still require review before publication. Sources are untrusted data.
- Lint compares working-tree raw/log with supplied trusted commit(s), not every historical commit
  or staged snapshot. Stage final content, run checks, review staged diff and commit that version.
  It does not prove branch provenance, remote reachability or that every cited statement is true.
- Inline Markdown file-link subset only; no external availability, heading-anchor, full CommonMark
  or code-fence parser. Exact versions are string labels, not semantic-version range resolution.
- Query structurally scans this small wiki before selecting up to five pages; no ranking/vector
  engine. It does not verify historical immutability or truth during retrieval. Inferences stay labeled.
- Locks coordinate CLI processes only; editor/other Git races and malicious filesystem races are
  outside scope. Git repo configuration/hooks are trusted local environment, not sandboxed code.
- Index and log use atomic replacement per file, with rollback on ordinary second-write failure;
  a crash/power loss can leave their pair inconsistent. Inspect diff, repair index and append a
  truthful event after recovery; no claim of cross-file transactional durability.
- A stale lock after abrupt termination is left intentionally. Confirm owner PID is inactive and
  inspect repository state before removing it manually. No automatic lock deletion or reset/clean.
- No real project integration, semantic LLM benchmark, Codex/Claude activation evaluation or
  remote publication. Owner/visibility/share scope/reviewer/target project still need decisions.
