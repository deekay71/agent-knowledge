# ADR 001 — Independent Markdown wiki pinned through submodules
Date: 2026-10-15. Status: accepted for local MVP.

Use a separate repository with raw immutable sources, compiled linked wiki and shared policy.
Use standard-library Python, JSON metadata in Markdown, deterministic committed navigation,
and explicit exact-version queries. No vector DB, model API, daemon or large cache.
Shared knowledge lives outside Unity Assets at knowledge/shared. Project knowledge and
unreviewed contributions stay in knowledge/project and knowledge/inbox. No automatic import.
Tradeoff: authoring/review remains agent-assisted/manual, with structural enforcement only.
Contribution worktrees isolate changes; an integrator reconciles log/index sequentially.
The CLI does not fetch, push, publish, or guess a remote. Pin changes require clean repos and
full locally present commit SHAs. Reading from detached submodules is expected.

Design references inspected 2026-10-15:
- https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f — raw/compiled wiki pattern.
- https://git-scm.com/docs/git-submodule — pinned submodule checkout and initialization.
- https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents — selective context.
Review gates, JSON schema and privacy boundaries are this MVP's decisions, not attributed standards.
