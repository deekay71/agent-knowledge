# ADR 004 — Evidence-aware graph exploration
Date: 2026-10-18 (UTC). Status: accepted for local implementation; publication separate.

## Context

The first viewer exposes explicit relations and source metadata but readers need to search
note bodies, follow evidence, recover navigation and identify incomplete references. These
operations must not infer factual relationships, run a model or expand filesystem access.

## Decision

Perform full-text retrieval and bounded graph traversal in the browser over the existing
eligible snapshot. Search is normalized literal matching, not semantic retrieval. Explain
each path through existing edges, their direction and provenance; traversal is navigation,
not proof of causation or truth. Respect visible type/topic/status/relation filters when
exploring. Retain the complete outgoing/backlink reader separately with its scope label.

Add bounded structural diagnostics for eligible missing references and disconnected pages.
Never read a missing target or manufacture a placeholder node/edge. Expose incomplete evidence
clearly; a declared page status is metadata, not a claim that the snapshot has passed review.
Privacy violations, unsafe paths, symlinks and malformed metadata remain fatal for the entire
snapshot. A diagnostic graph is a reading aid, not a replacement for canonical lint or review.

Copy context only on a deliberate user action. Include canonical paths, source versions,
evidence/inference/unknown labels, snapshot identity and any incompleteness warnings. Bound
the output and disclose truncation. Copying does not write knowledge or submit content to an
external service; the user chooses where to paste the result.

Use browser navigation state and a bounded URL fragment for deep links. Navigation must
restore the selected note/edge and reader state without fetching arbitrary paths. Refresh
must reconcile against actual snapshot IDs; stale or invalid selections cannot invent notes.
Keep note bodies out of URLs and persisted navigation state.

## Consequences

The API remains additive to format 1. Diagnostic-only snapshots can be rendered while
invalid/private snapshots fail closed. Search results and paths are deterministic for the
same eligible graph and filters; they do not certify source quality or semantic completeness.
All datasets used for demonstrations and browser QA remain separate synthetic fixtures.

The Git authoring, submodule pinning, immutable raw-source and append-only log workflows are
unchanged. Phase P1 is a separate local commit after the published MVP. Validation evidence
must distinguish actual browser behavior from captured clipboard-adapter calls and from
untested OS clipboard integrations.
